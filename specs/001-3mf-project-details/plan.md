# Implementation Plan: 3MF Project Details Display

**Branch**: `001-3mf-project-details` | **Date**: 2026-08-11 | **Spec**: [spec.md](spec.md)

**Input**: Feature specification from `specs/001-3mf-project-details/spec.md`

---

## Summary

Add a read-only "Informações 3MF" section to the existing Details panel that extracts and displays project metadata (model title, designer, description, creation date) and print profile settings (profile name, layer height, wall count, infill %) from `.3mf` ZIP archives. Metadata is fetched on-demand asynchronously when a `.3mf` object is selected; it is never persisted to the database. The section is fully hidden when no metadata is found or when a non-3MF object is selected.

---

**Language/Version**: C# 13, .NET 10

**Primary Dependencies**: Avalonia 12 (UI + compiled bindings), CommunityToolkit.Mvvm 8.4.2, `System.IO.Compression` (ZIP reading — BCL), `System.Xml.Linq` (3MF XML parsing — BCL), `System.Text.Json` (Bambu JSON parsing — BCL)

**Testing**: No test project in repository. Manual testing via the running application.

**Target Platform**: Windows desktop (WinExe, .NET 10)

**Project Type**: Desktop application (Avalonia MVVM)

**Performance Goals**: Metadata extraction visible within 1 second of object selection (SC-001). ZipFile + XDocument reads on small metadata-only blocks are typically <10ms.

**Constraints**:
- All UI updates must occur on the Avalonia UI thread (`Dispatcher.UIThread.Post`).
- AXAML must use `CompiledBinding` / `x:DataType` (project-wide: `AvaloniaUseCompiledBindingsByDefault=true`).
- No new NuGet packages; use only BCL types already available in .NET 10.

**Scale/Scope**: Single-user, local files. Extracts from one file at a time per selection.

| Unknown | Decision |
|---------|----------|
| 3MF metadata file locations | Standard: `3D/3dmodel.model` XML; Bambu/Orca: `Metadata/project_settings.config` (JSON); PrusaSlicer: `Metadata/Slic3r_PE.config` (INI) |

## Phase 1: Design

### New Model: `ThreeMfProjectInfo`

```csharp
// src/STLHub/Models/ThreeMfProjectInfo.cs
public sealed record ThreeMfProjectInfo
{
    // Standard 3MF identity metadata (from 3D/3dmodel.model)
    public string? Title { get; init; }
    public string? Designer { get; init; }
    public string? Description { get; init; }
    public string? CreationDate { get; init; }

    // Print profile fields (from slicer-specific config files)
    public string? ProfileName { get; init; }
    public string? LayerHeight { get; init; }
    public string? WallCount { get; init; }
    public string? InfillPercent { get; init; }
    public string? ProfileAuthor { get; init; }

    // Computed helpers used for UI visibility
    public bool HasAnyMetadata =>
        Title != null || Designer != null || Description != null || CreationDate != null ||
        ProfileName != null || LayerHeight != null || WallCount != null ||
        InfillPercent != null || ProfileAuthor != null;

    public bool HasAnyProfileData =>
        ProfileName != null || LayerHeight != null || WallCount != null ||
        InfillPercent != null || ProfileAuthor != null;
}
```

### `MainWindowViewModel` additions

```csharp
// New backing field
private CancellationTokenSource? _projectInfoCts;

// New observable properties (CommunityToolkit.Mvvm [ObservableProperty])
[ObservableProperty] private ThreeMfProjectInfo? _projectInfo3mf;
[ObservableProperty] private bool _isProjectInfo3mfLoading;

// New computed property
public bool IsProjectInfo3mfVisible =>
    SelectedObject?.FileType.Equals(".3mf", StringComparison.OrdinalIgnoreCase) == true &&
    (IsProjectInfo3mfLoading || ProjectInfo3mf?.HasAnyMetadata == true);

// Extension to existing OnSelectedObjectChanged partial method
_projectInfoCts?.Cancel();
ProjectInfo3mf = null;
IsProjectInfo3mfLoading = false;
if (value?.FileType.Equals(".3mf", StringComparison.OrdinalIgnoreCase) == true)
{
    _projectInfoCts = new CancellationTokenSource();
    IsProjectInfo3mfLoading = true;
    _ = LoadProjectInfoAsync(value.MainFilePath, _projectInfoCts.Token);
}

// New private method
private async Task LoadProjectInfoAsync(string filePath, CancellationToken ct)
{
    var info = await ThreeMfMetadataReader.ReadAsync(filePath, ct);
    if (ct.IsCancellationRequested) return;
    Dispatcher.UIThread.Post(() =>
    {
        ProjectInfo3mf = info;
        IsProjectInfo3mfLoading = false;
        OnPropertyChanged(nameof(IsProjectInfo3mfVisible));
    });
}
```
